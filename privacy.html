nas-media-uploader プライバシーポリシー

更新日: 2026年11月14日。

対象と目的

このツールは所有者本人が管理するNASとクラウドアカウントで使用する個人用ツールです。Googleから取得するデータは、本人のチャンネル確認、動画の非公開アップロード、処理結果・公開範囲の確認、必要時の非公開への修正に使用します。

アクセスする情報と送信先

Google OAuthのアクセストークン・更新トークン、YouTubeチャンネルID、動画ID・公開範囲等のAPI応答を取り扱います。指定動画のファイル内容をYouTubeへ送信します。動画タイトルにはSHA-256の一部、説明には重複管理用のSHA-256を設定します。動画の公開範囲はprivateを指定します。

認可対象には動画の編集・削除を含み得る権限がありますが、本ツールの実装は動画削除を行わず、公開範囲をprivateへ修正するために編集機能を使用します。

Flickr連携を使用する場合、指定JPEGとアルバム名をFlickrへ送信します。アルバム名には対象フォルダ名が含まれます。FlickrとGoogleの認証情報は分離します。

保存と保護

認証情報は所有者限定権限の専用ファイルへ保存し、ソースコードや一般配布物から分離します。動画ID、ハッシュ、進行状態、再開可能アップロードのセッション情報等を実行環境のSQLite履歴へ保存します。履歴とバックアップには秘密情報が含まれ得るため、アクセスを所有者に制限します。原本は読み取り専用で参照します。

利用・共有の制限

本ツールはGoogleユーザーデータを販売せず、広告目的で利用せず、汎用AIモデルの学習用に転送しません。Google API Services User Data PolicyのLimited Use要件に従って利用します。送信先サービスでの取り扱いには各サービスのプライバシーポリシーが適用されます。

保持と利用停止

ローカル認証情報・履歴は所有者が管理し、自動で期限削除しません。利用停止時はまず実行を停止し、Googleアカウントの第三者アクセス管理から認可を取り消せます。ローカルの認証情報やバックアップを廃棄する場合は所有者が個別に実施します。履歴を消すと重複防止情報が失われるため、再開前に送信済み記録の確認が必要です。クラウド上の動画削除は自動連動しません。

問い合わせ

所有者本人が管理します。認可画面に表示されるユーザーサポートメールへお問い合わせください。パスワードやトークンは送付しないでください。
